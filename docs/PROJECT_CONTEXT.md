# Project context

## Overview

Marco Polato's personal and professional portfolio,
presenting his experience as a web and mobile software
developer, technical coordination responsibilities,
education, projects, and personal interests.

## Objectives

- Present professional experience and technical skills.
- Showcase projects and actual personal contributions.
- Establish a professional online presence.
- Provide a contact point for potential collaborations.
- Build a reusable foundation for future showcase websites.

## Target audience

- Recruiters and potential employers.
- Companies and prospective clients.
- Technology professionals and collaborators.

## Learning objectives

The project is also a practical learning environment for:

- Astro architecture and static site generation.
- Modern frontend development.
- Responsive design and UI/UX.
- Web accessibility, SEO, and performance.
- Animations and microinteractions.
- Reusable components and website architecture.

## Product decisions

- Keep the homepage concise and informative.
- Give professional experience and projects dedicated pages.
- Describe real experience, skills, and contributions.
- Support Italian and English with equivalent content.
- Provide light and dark themes.
- Preserve the selected theme across navigation.

## Architecture decisions

- Use Astro with TypeScript and static site generation.
- Prefer native CSS and targeted browser JavaScript.
- Avoid unnecessary client-side frameworks and dependencies.
- Share page content and components across languages.
- Keep the architecture suitable for future reuse.

See [coding rules](CODING_RULES.md) for implementation
details and repository conventions.

## Languages and navigation

Italian is served at the root and English under `/en/`.

Language switching must preserve the equivalent page
or project whenever available.

## Visual direction

The portfolio follows a distinctive editorial visual
identity, balancing professional presentation and
personal expression.

See [design system](DESIGN_SYSTEM.md) for visual
principles, design tokens, components, and motion.
